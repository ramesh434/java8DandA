// Coding principles
Every developer should follow SOLID principles
S- Single Responsibility
O- Open & Close
L- Luknov Substitution
I- Interface seggeregation
D- Dependency Inversion.

Single Responsibility : A class can be changed for only one reason
Open & Close : Entities ( Classes , functions, modules ) should be open for extension & closed for modifications
